# Car Park API

## Running the application
### MAC
To run the application on mac
```sh
./gradlew bootRun
```

### WINDOWS
To run the application on windows
gradlew bootRun


## Testing 
To ru the tests, run the command : 
```sh
./gradlew test
```

## Assumptions
Carpark capacity is 50
Maximum 7 characters on a numberplate
When the bill POST is made, this implies a vehicle has exit the carpark
